## 1. 屏幕怎么选？（为什么选 ST7789 240×240 IPS）

做桌面 AI 状态显示器，需要同时满足：**能清晰显示中英文混排、刷新够快、颜色对比度高、接口简单、价格便宜**。常见小屏幕对比如下：

| 屏幕芯片 | 典型尺寸与分辨率 | 接口 | 颜色/面板 | 适用性评估 |
|---|---|---|---|---|
| **ST7789（本项目推荐）** | **1.3" 或 1.54" 240×240** | **4线 SPI** | **RGB565 IPS 彩屏** | **最佳选择**：12px 中文字一行能排 18~20 字，可视角度大（IPS），27MHz SPI 可达 20+fps，淘宝 ¥10~18 |
| ST7735 | 0.96"~1.8" 128×160 | 4线 SPI | RGB565 TFT（多为 TN） | 分辨率太低，显示中文步骤条和命令摘要太挤 |
| GC9A01 | 1.28" 240×240 圆形 | 4线 SPI | RGB565 IPS 圆形 | 四个角被裁掉，不适合本项目的矩形卡片式 UI |
| ILI9341 | 2.4"~2.8" 240×320 | 4线 SPI | RGB565 TFT | 信息量更大，但整屏帧缓冲需 150KB 且初始化命令与 ST7789 不同（需改 `panel.c`） |
| SSD1306 / SH1106 | 0.96"~1.3" 128×64 | I2C (400kHz) | 单色 OLED | 面积小、无色彩区分状态（思考/等待输入/报错），信息密度不足 |

### 买 ST7789 模块时的 4 个关键避坑点
1. **认准 `1.3寸` 或 `1.54寸 240×240 IPS ST7789`**：
   - `1.3寸`（常见 7 针：无 CS 脚）和 `1.54寸`（常见 8 针：带 CS 脚）驱动芯片完全相同。
   - **强烈建议新手买 8 针带 CS 脚的 1.54 寸模块**（面积大一点点更护眼，且有 CS 脚抗干扰更强）；如果买到 7 针无 CS 脚的模块也完全支持（与本项目默认配置完全一致）。
2. **确认逻辑电平是 3.3V**：绝大多数裸屏/排针 ST7789 模块工作电压都是 **3.3V**（部分 1.54 寸板载了 LDO 支持 3.3V~5V VCC，但信号线依然用 3.3V）。直接接 ESP32-C3 的 3.3V 即可。
3. **IPS 屏必须开启颜色反相（`INVON = 0x21`）**：如果点亮后黑底变白底、蓝色变黄色，就是少了 `0x21` 命令（本项目 `menuconfig` 的 `ZTV_LCD_INVERT` 默认为 `y`）。
4. **7 针无 CS 模块的 SPI Mode 3 铁律**：
   - ST7789 芯片在 `CS` 引脚被模块内部直接拉低（接地）时，如果主机用常见的 SPI Mode 0（`CPOL=0`），空闲时钟为低，容易和芯片内部移位寄存器相位错位导致**完全黑屏或花屏**；
   - **必须使用 SPI Mode 3（`CPOL=1, CPHA=1`）**：时钟空闲为高电平，上升沿采样数据。这正是本固件 `CONFIG_ZTV_LCD_SPI_MODE=3` 的原因。

## 3. 核心电路详解（模拟电路视角）

### 3.1 为什么背光必须用三极管 / MOS 管？以及极性陷阱

一块 1.3"~1.54" 屏幕内部通常有 1~3 颗并联的白光 LED（VF ≈ 3.0V），总电流 **30~60mA**。直接接 ESP32 GPIO 会过载拉垮端口电压甚至烧 IO。市售板子常见两种背光驱动电路：

#### 电路 A：低电平有效（PNP 三极管 / P-MOSFET，本项目小电视硬件）
```text
                      +3.3V
                        │
                        ├─── 10kΩ (上拉电阻，默认关灯)
                        │      │
                        E      │
       GPIO1 ── 1kΩ ─── B  PNP (如 S8550 / AO3401 P-MOS)
                        C
                        │
                       [R_lim 10~22Ω]
                        │
                     (LED_A +)  背光 LED 灯串
                     (LED_K -)
                        │
                       GND
```
- **工作原理**：
  - `GPIO1 = 0V`（低电平）→ PNP 的 `V_EB ≈ 0.7V` 导通 → 电流从 `+3.3V` 流过 LED 到 `GND` → **最亮（100%）**；
  - `GPIO1 = 3.3V`（高电平）→ `V_EB = 0V` 截止 → **熄灭（0%）**；
  - 对应本固件配置：`CONFIG_ZTV_LCD_BL_ACTIVE_LOW=y`（默认），或在线执行 `python3 host/agy_tv.py bl --inv 1`。
- **这就是之前暗屏的真实原因**：旧代码在 `100%` 时输出了 `duty=255/256`（99.6% 时间是高电平），只留下 `0.4%` 的低电平，LED 处于微弱导通态，肉眼勉强可见但非常暗！

#### 电路 B：高电平有效（NPN 三极管 / N-MOSFET，常见于部分 1.54" 散件模块）
```text
                      +3.3V
                        │
                     (LED_A +)  背光 LED 灯串
                     (LED_K -)
                        │
                       [R_lim 10~22Ω]
                        │
                        C
       GPIO1 ── 1kΩ ─── B  NPN (如 S8050 / AO3400 N-MOS)
                        E      │
                        │     10kΩ (下拉电阻，默认关灯)
                       GND     │
                              GND
```
- **工作原理**：
  - `GPIO1 = 3.3V`（高电平）→ NPN 导通 → **最亮（100%）**；
  - `GPIO1 = 0V`（低电平）→ NPN 截止 → **熄灭（0%）**；
  - 如果你买到的 DIY 屏幕模块是这种电路，刷完本固件后无需改代码，直接执行 `python3 host/agy_tv.py bl --inv 0`（或在 `menuconfig` 里关掉 `ZTV_LCD_BL_ACTIVE_LOW`）即可！

> **快速用电源/万用表验证你买的屏幕属于哪一种**：屏幕接好 3.3V 和 GND 后，把 `BLK` 脚通过一颗 `1kΩ` 电阻碰一下 `3.3V`，再碰一下 `GND`——碰哪边亮，哪边就是有效电平！

## 4. 完整引脚接线表（与默认固件零修改直通）

直接按以下引脚连接，刷入本仓库默认编译的固件即可直接点亮，无需修改任何引脚配置：

| ST7789 屏幕模块引脚 | 连接到 ESP32-C3 引脚 | 信号方向 | 作用与注意事项 |
|---|---|---|---|
| **VCC** | **3V3** | 电源 | 严禁接 5V（除非确认模块板载 3.3V LDO） |
| **GND** | **GND** | 地线 | 务必与 ESP32 共地，尽量短粗 |
| **SCL / SCLK / SCK** | **GPIO3** | ESP32 → 屏 | SPI 时钟（默认 27MHz，面包板建议先降到 10~20MHz） |
| **SDA / MOSI** | **GPIO5** | ESP32 → 屏 | SPI 数据输出（本项目只写屏不读屏，无需 MISO） |
| **DC / RS / A0** | **GPIO2** | ESP32 → 屏 | 数据/命令选择（0=命令，1=像素数据；**注意 GPIO2 是 Strapping 脚，勿接外部下拉**） |
| **RES / RST** | **GPIO6** | ESP32 → 屏 | 硬件复位（低电平复位 20ms，释放后等 150ms） |
| **CS** | **GND**（或接任意空闲脚如 GPIO7 并在 `menuconfig` 设置 `ZTV_LCD_PIN_CS=7`） | ESP32 → 屏 | 7 针无 CS 模块已内置接地；8 针模块若直接接 GND 则保持 `CS=-1` 即可 |
| **BLK / BL** | **GPIO1** | ESP32 → 屏 | 5kHz PWM 背光调光（若模块无 BLK 脚则背光常亮，设 `ZTV_LCD_PIN_BL=-1`） |

```text
   ┌───────────────────┐                ┌────────────────────┐
   │    ESP32-C3       │                │  ST7789 240x240    │
   │                   │                │     IPS LCD        │
   │  3V3 ─────────────┼───┬────────────┤ VCC                │
   │  GND ─────────────┼───┼───┬────────┤ GND                │
   │                   │  ═╪═ 0.1uF     │                    │
   │                   │   └───┘        │                    │
   │  GPIO3 (SCLK) ────┼────────────────┤ SCL                │
   │  GPIO5 (MOSI) ────┼────────────────┤ SDA                │
   │  GPIO2 (DC)   ────┼────────────────┤ DC                 │
   │  GPIO6 (RST)  ────┼────────────────┤ RES                │
   │  GPIO1 (BL)   ────┼────────────────┤ BLK                │
   │  (GND)        ────┼────────────────┤ CS (8针模块可接地)  │
   └───────────────────┘                └────────────────────┘
```

### 如果你的开发板引脚布局不同
不用改 C 代码！在项目目录运行 `idf.py menuconfig` → 进入 **`AGY TV (ESP32 status display)` → `LCD panel`**，所有引脚（SCLK/MOSI/DC/RST/CS/BL）、SPI 频率、SPI 模式、屏幕旋转（`0..3`）、颜色反相和背光极性全部可图形化配置。

## 5. 面包板高速 SPI 搭电路的模拟注意事项

你具备模拟电路基础，可以把 **27MHz 方波**想象成包含 **100MHz+ 高频谐波**的信号（方波上升沿约 `2~5 ns`，等效带宽 $f \approx 0.35 / t_r \approx 70\text{~}175\text{ MHz}$）：

1. **杜邦线不要超过 10cm**：长导线有几十 nH 寄生电感和几十 pF 分布电容，在 27MHz 时钟下会形成明显的 LC 振铃（过冲/下冲），屏幕可能误采时钟边沿导致花屏或移位。
2. **信号线旁边贴一根 GND 回流线**：高频信号需要紧贴的地回流路径以减小环路面积。
3. **面包板首调先降频**：第一次在面包板上点屏时，先把 `menuconfig` 里的 `ZTV_LCD_SPI_CLOCK_KHZ` 设为 **`10000`（10MHz）** 或 **`4000`（4MHz）**——能稳定点亮后，再用示波器看着 SCLK 波形逐步拉高到 `20000` / `27000` / `40000`。
4. **如果示波器看到 SCLK 严重过冲振铃**：在 ESP32 输出端串联一颗 **`22Ω ~ 47Ω` 源端阻尼电阻**（模拟电路里的经典阻抗匹配！），波形立刻干净。
