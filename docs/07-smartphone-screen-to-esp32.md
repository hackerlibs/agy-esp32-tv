# 07. 进阶实战：如何给 ESP32 接一块二手手机屏幕（电路设计与避坑指南）

很多电子爱好者手里都有几块拆机或淘汰的二手手机屏，分辨率高、色彩惊艳、甚至带触摸，很自然会想：「能不能把它接到 ESP32 上当超大超清的 AGY 桌面显示器？」

这篇从**模拟电源、高速接口、芯片选型、PCB 工艺和仪器调试**五个维度，把「ESP32 点亮二手手机屏」这件事讲透——既让你知道**为什么不能像 1.54" ST7789 那样直接飞 6 根线点亮**，也给你完整的电源/升压/电平转换/接口电路设计方案。

---

## 1. 先给大实话：你的二手手机屏能不能直接接 ESP32？

能否点亮、要画多复杂的电路，**完全取决于手机屏的接口类型和 ESP32 型号**：

| 手机屏类型 | 常见来源 | 接口与速率 | ESP32-C3（本项目） | ESP32-S3 | **ESP32-P4（新一代）** |
|---|---|---|---|---|---|
| **老式并口/SPI 屏** | 2012 年前功能机、老诺基亚、部分 480×800 早期安卓拆机屏（如 `NT35510`、`OTM8009A`） | 8/16-bit 8080 并口或 SPI | 引脚不够 / 显存太小 | **可直驱**（8080/RGB + 8MB PSRAM） | 可直驱 |
| **穿戴/小尺寸 QSPI AMOLED 屏** | 拆机智能手表、手环、部分折叠机外屏（如 `RM67162`、`CO5300`） | **4 线 QSPI**（~80MHz） | 勉强（无 PSRAM 需分块刷） | **非常合适！**（自带 QSPI + PSRAM） | 非常合适 |
| **现代智能机 2-Lane MIPI 屏** | 2014~2020 年 720p / 部分 1080p 手机屏、iPhone 4/4S 拆机屏 | **MIPI-DSI (2-Lane)**，每通道 500M~1.5Gbps | **硬件不支持**（需外挂桥接芯片） | **硬件不支持**（需外挂 `SSD2828` 等桥接芯片） | **原生直驱！**（内置 2-Lane MIPI-DSI + 32MB PSRAM） |
| **旗舰机 4-Lane 高刷 OLED 屏** | 近年主流安卓/iPhone 1080p+/2K 120Hz 柔性屏 | **MIPI-DSI (4-Lane)** + 私有加密/复杂时序 | 不支持 | 不支持 | 通道数不够（需 FPGA / 树莓派 / RK3566） |

> **工程性价比提醒（动手前先算一笔账）**：
> - 如果你的目标是**尽快做一个大屏 AGY 显示器**：淘宝买一块带开源资料的 **3.5"~4.3" ESP32-S3 RGB/QSPI 屏**（约 ¥50~¥90）或 **ESP32-P4 + 配套 MIPI 屏**，能省下 90% 踩坑时间；
> - 如果你的目标是**练手模拟电源（Boost 升压、正负电荷泵）、高速差分 PCB 和逆向调试**，拿一块有公开维修图纸的经典二手手机屏来画板点亮，绝对是含金量极高的硬核项目！

## 2. 二手手机屏电路设计的 5 大硬核模块

和我们项目里「一根 `3.3V` + 5 根 3.3V SPI 线」的 1.54" ST7789 模块不同，一块裸的二手手机屏通常需要下面 **5 块独立电路** 协同工作：

```text
                       ┌──────────────────────────────────────────┐
                       │         手机屏电源管理子系统（核心！）       │
                       │  ① 1.8V LDO       ──► IOVCC (逻辑电源)   │
                       │  ② 2.8V~3.3V LDO  ──► VCI/AVDD (模拟电源)│
   USB 5V ────────────►│  ③ TPS65132       ──► VSP(+5.5V)/VSN(-5.5V) (LCD偏压)
   (≥1A)               │     (或 OLED PMIC ──► ELVDD+4.6V/ELVSS-3V)│
                       │  ④ SY7200A Boost  ──► LED_A/K (18~26V恒流背光)
                       └────────────────────┬─────────────────────┘
                                            ▼
  ┌──────────────────┐  1.8V电平转换  ┌─────────────┐   0.35/0.4mm   ┌─────────────┐
  │ ESP32-P4 / S3    ├──────────────►│ RST / TE /  ├───────────────►│  二手手机屏  │
  │ (或 S3+SSD2828)  │  100Ω差分等长  │  I2C 触摸   │    BTB 连接器   │  (LCD/OLED) │
  │                  ├──────────────►│ MIPI-DSI    ├───────────────►│             │
  └──────────────────┘               └─────────────┘                └─────────────┘
```

## 3. 电源电路设计（模拟电路最核心的部分！）

### 3.1 逻辑电源 `IOVCC (1.8V)` 与模拟电源 `VCI (2.8V ~ 3.0V)`
手机屏芯片为了省电和高速，几乎全部采用 **`1.8V` 数字逻辑电平**，另配一路低噪声 **`2.8V`** 模拟供电给内部伽马 DAC：

```text
  5V/3.3V ──┬──► [ ME6211C18 / RT9013-18GB ] ──┬──► IOVCC = 1.8V (≥150mA)
            │           (GND)                  │
           ═╪═ 1uF                            ═╪═ 1uF + 0.1uF (紧贴 BTB 座!)
            │                                  │
           GND                                GND

  5V/3.3V ──┬──► [ ME6211C28 / LP5907-2.8 ]  ──┬──► VCI / AVDD = 2.8V (≥150mA)
            │           (GND)                  │
           ═╪═ 1uF                            ═╪═ 1uF + 0.1uF
            │                                  │
           GND                                GND
```
- **避坑**：如果手机屏数据手册要求「先上 `1.8V` 再上 `2.8V`」，选带 `EN` 使能脚的 LDO（如 `RT9013` / `ME6211`），把 `EN` 接到 ESP32 的 GPIO 上，由代码按 `IOVCC → 延时 5ms → VCI → 延时 10ms → 拉高 RST` 的精确顺序控制上电！

---

### 3.2 LCD 手机屏专用：正负对称偏压 `VSP (+5.5V) / VSN (-5.5V)`
2015 年后的绝大多数手机 IPS 液晶屏（如红米、荣耀、小米的 720p/1080p 屏幕）内部没有电荷泵，必须由主板提供一对正负高压偏置 **`VSP = +5.5V`、`VSN = -5.5V`**（典型 ±5.0V ~ ±5.8V，电流 40~80mA）才能驱动液晶偏转。

**不要自己分立搭两路 DC-DC！** 直接用手机主板同款专用芯片：**`TPS65132`**（TI）或国产平替 **`SGM3804` / `SM5109`**（立创商城约 ¥3~¥6）：

```text
                         L1 = 4.7uH (饱和电流 ≥ 1.5A)
  USB 5V ──┬──────────────[mmmm]──────────┬──► SW (TPS65132)
           │                              │
          ═╪═ 10uF                  ┌─────┴───────────┐
           │                        │   TPS65132 /    │
          GND                       │   SGM3804       │
                                    │                 ├──► OUTP = VSP (+5.5V) ──┬──► 接屏 VSP
   ESP32 GPIO ─────────────────────►│ ENP (正压使能)   │                        ═╪═ 10uF (16V X7R)
   ESP32 GPIO ─────────────────────►│ ENN (负压使能)   │                         │
   ESP32 I2C (1.8V/3.3V) ──────────►│ SDA / SCL       │                        GND
                                    │   (可选调电压)   │
                                    │                 ├──► OUTN = VSN (-5.5V) ──┬──► 接屏 VSN
                                    │   CFLY (飞电容)  │                        ═╪═ 10uF (16V X7R)
                                    │  ┌───[2.2uF]───┐│                         │
                                    └──┴─────────────┴┘                        GND
```
- **亮点**：默认上电就是标准的 **`+5.0V / -5.0V`** 或 **`+5.5V / -5.5V`**（视具体尾缀型号而定），还支持通过 I2C 微调到 ±5.4V、±5.8V 等精准电压；而且自带 `ENP`/`ENN` 独立使能脚，完美配合屏幕手册的上电时序要求！

*(如果你拆的是 **AMOLED 手机屏**，则需要专门的 AMOLED PMIC 如 `TPS65632` / `SGM38042` 产生 `ELVDD (+4.6V)` 和 `ELVSS (-2.4V ~ -4.4V)`，原理类似，也是单芯片方案。)*

---

### 3.3 LCD 手机屏专用：18V ~ 28V 恒流升压背光电路（最容易踩的模拟坑！）

这是和小电视 1.54" 屏差异最大的地方：
- 1.54" 小屏只有 2~3 颗背光灯珠**并联**，`3.3V` + 限流电阻直接点亮；
- 5~6.5 寸手机 LCD 屏往往有 **6 ~ 10 颗白光 LED 串联**（或者 2 路各 6~8 颗串联），每颗正向压降 `VF ≈ 3.0V`，整串导通电压高达 **`18V ~ 28V`**！
- **绝对不能用普通升压模块直接调 24V 恒压去接 LED！** 温度一升高 LED $V_F$ 下降，电流会雪崩飙升瞬间烧毁整个背光灯条。**必须用恒流 Boost 升压芯片**！

#### 经典低成本恒流升压电路：`SY7200A` / `MT9284` / `SGM3732`（约 ¥1~¥2）
```text
                    L1 = 10uH (≥1A)      D1 = SS34 / B5819 (40V 肖特基)
  USB 5V ──┬──────────[mmmm]──────────┬───────►|───────┬──────► LED_A (+18V~28V)
           │                          │                │             │
          ═╪═ 10uF                    │               ═╪═ C_out     [手机屏内部
           │                    ┌─────┴─────┐          │  1uF/50V    6~8颗串联LED]
          GND                   │  LX (SW)  │          │  (耐压≥50V!) │
                                │           │         GND            ▼
                                │  SY7200A  │                  LED_K (灯串负极)
   ESP32 PWM (1~20kHz) ────────►│ EN / PWM  │                        │
   (可直接调亮度！)               │           │        ┌───────────────┘
                                │    FB     ├────────┤
                                │   (GND)   │        │
                                └─────┬─────┘      [R_SET]  例如 10Ω (1/4W)
                                      │              │      I_LED = V_FB / R_SET
                                     GND            GND     = 0.2V / 10Ω = 20mA!
```

#### 模拟电路设计要点（必读！）
1. **恒流公式**：以 `SY7200A`（内部基准 $V_{FB} = 0.2\text{V}$）为例：
   $$I_{LED} = \frac{V_{FB}}{R_{SET}} = \frac{0.2\text{V}}{10\Omega} = 20\text{ mA}$$
   - 手机单串背光安全电流一般在 **`15 ~ 20 mA`**（如果是双串 `LED_K1 / LED_K2` 并联进 `FB`，总电流设为 `35 ~ 40 mA`，或在两路阴极各串一颗小均衡电阻 `10Ω`）。
   - **首次点亮陌生手机屏时，先焊 `R_SET = 20Ω`（仅 10mA）**，安全又护眼，绝不会烧灯珠！
2. **输出电容 `C_out` 耐压必须 ≥ 50V**（选 `1uF / 50V X7R`），且注意开路保护：如果没接屏幕就上电，Boost 会一直往上冲电压直到触发芯片过压保护（OVP，一般 28~38V），所以**务必先接好屏幕再通电**，或在芯片选型时确认带内置 OVP。
3. **调光极简单**：直接把 ESP32 的背光 PWM 脚（如本项目 `GPIO1`）接到 `SY7200A` 的 `EN/PWM` 脚即可，完全兼容本项目的 `agy_tv.py bl <0..100>` 命令！

## 4. 电平转换、连接器与高速 MIPI-DSI 布线

### 4.1 1.8V ↔ 3.3V 电平转换（控制信号线）
手机屏的 `RST`（复位）、`TE`（帧同步）、`TP_SDA/TP_SCL/TP_INT`（电容触摸屏 I2C）几乎全是 **1.8V 电平**：
- **推荐芯片**：**`SN74AXC4T774`**（4 通道方向可控，完美支持单向 SPI/RST/TE）和 **`TXS0102` / `PCA9306`**（双向开漏，专门给 1.8V I2C 触摸用）；
- **模拟偷懒方案（仅限单向低速脚如 `RST`）**：ESP32 `3.3V` 输出 → 串 `1.5kΩ` + 下拉 `1.8kΩ` 到 GND → 分压得 `1.8V` 进屏幕 `RST` 脚！

### 4.2 0.35mm / 0.4mm BTB 连接器怎么选、怎么画？
- 拆下二手手机屏后，用游标卡尺或显微镜数清排线末尾 **BTB 公座的针数（常见 24P / 30P / 34P / 40P）和间距（0.35mm 或 0.40mm）**；
- 找对应手机型号的维修点位图/原理图（如搜索 `<型号> schematic pdf` 或用立创开源广场搜同类拆机屏转接板），确认每一脚定义；
- **最省心的做法**：把「电源电路 + BTB 母座 + 电平转换」画成一块 **4 层小转接板** 走嘉立创 SMT 贴片（BTB 母座和 `TPS65132` 这种 QFN/BGA 小封装让嘉立创贴，比自己拿热风枪吹靠谱十倍！）。

### 4.3 MIPI-DSI 高速差分 PCB 走线规则（如果用 ESP32-P4 或 SSD2828）
MIPI-DSI 数据通道频率高达几百 MHz，必须当成射频/传输线来画：
1. **层数**：强烈建议 **4 层板**（L1 信号、L2 完整 GND 地平面、L3 电源、L4 低速控制信号），嘉立创 10×10cm 4 层板也经常有特惠打样；
2. **100Ω 差分阻抗**：在嘉立创「阻抗计算神器」选 `JLC04161H-7628` 层叠，计算 `100Ω` 差分线宽/线距（通常约 `0.15mm 线宽 / 0.15mm 间距`，具体以计算器为准）；
3. **等长绕线**：同一对差分线（如 `D0+` 与 `D0-`）长度差 **≤ 0.15 mm**；不同对之间（`CLK` 与 `D0/D1`）长度差 **≤ 1.0 mm**；
4. **禁止跨分割**：差分线正下方的 L2 地平面必须完整连续，不能被电源槽割断；尽量不打过孔，万不得已换层时在差分过孔旁放一对 **接地回流过孔（GND stitching vias）**。

## 5. 最难的一关：如何拿到初始化序列（Init Code）与驱动？

硬件全部焊好、电压全对，手机屏依然会黑屏——因为屏幕玻璃里的驱动 IC 必须收到一串**几十到上百条私有 MIPI DCS 初始化命令**后才会出图。

**实战拿到初始化代码的 3 条路径**：
1. **首选：查该手机型号的 Linux / Android 内核源码（最靠谱！）**：
   - 去 GitHub 搜索 `<手机代号> kernel dtsi panel`（例如 `xiaomi`, `redmi`, `oneplus`, `motorola` 几乎都在 GitHub 开源了 Android 内核！）；
   - 在内核源码的 `arch/arm64/boot/dts/qcom/dsi-panel-*.dtsi` 文件里，你会直接找到：
     - `qcom,mdss-dsi-on-command` → **这就是完整、100% 准确的十六进制初始化序列！**
     - `qcom,mdss-dsi-panel-width / height / h-front-porch / h-back-porch / v-sync-pulse-width` → **精确的时序参数！**
     - `qcom,mdss-dsi-lane-map` 和电源电压值！
2. **次选：选社区已经做过开源驱动的经典二手屏**：
   - 例如 **iPhone 4/4S Retina 屏**、**小米/红米 `ILI9881C` / `HX8394` / `NT35521` 屏**、或 **手表拆机 `RM67162` / `SH8601` QSPI AMOLED 屏**——网上已有现成的 ESP-IDF / Arduino 驱动代码。
3. **硬核玩法：在原手机主板上抓包**：
   - 如果原手机还能开机，用高带宽逻辑分析仪抓 MIPI LP（Low-Power 1.2V 模式，速度仅 ~10MHz！）的初始化命令（手机屏初始化大多是在低速 LP 模式下发送的，100MHz 逻辑分析仪就能抓到！）。

## 6. 用你手头的仪器「体检」二手手机屏（实操步骤）

收到或拆下一块二手手机屏，**千万别急着画主板，先用仪器 4 步验尸/点亮测试**：

### 第 1 步：万用表二极管档体检（断电）
- 红表笔接 `GND`，黑表笔逐个点测 BTB 脚的压降：
  - `0.00V` → `GND` 脚；
  - `0.35V ~ 0.70V` → 正常的 CMOS 信号脚或电源脚（内部 ESD 保护二极管压降）；
  - `OL`（无穷大）→ 可能是 `NC` 空脚或串联高压背光 `LED_A` 脚（串联 6 颗 LED 压降 ~18V，万用表二极管档的 2.5V 打不开）。

### 第 2 步：独立点亮背光（验证灯条好坏，零风险！）
- 找到 `LED_A` 和 `LED_K` 后，接上第 3.3 节搭好的 **`SY7200A` 恒流升压小板**（设 `R_SET = 20Ω` 即 10mA），或用可调直流电源**先限流 10mA**，慢慢从 12V 往上调电压：
  - 调到 **`18V ~ 24V`** 附近时，电流表突然跳到 10mA、屏幕背光均匀亮起白底 → **恭喜，背光灯条完全完好，同时你也精确测出了这块屏的背光工作电压！**

### 第 3 步：示波器验收多路电源与上电时序
- 在空载（先不扣屏幕）时，用示波器逐一检查转接板输出：
  - `IOVCC = 1.80V ± 0.05V`、`VCI = 2.80V ± 0.05V`；
  - `VSP = +5.5V`、`VSN = -5.5V`（纹波 < 50mV）；
  - 确认没有任何一路电压超标后再断电扣上手机屏！

### 第 4 步：示波器测 `TE` 信号——判断屏幕有没有「活过来」的终极标志！
- 扣上屏幕、跑完初始化代码后，如果屏幕还是黑的，用示波器 `10X` 探头点一下屏幕的 **`TE`（Tearing Effect）引脚**（直流耦合，`1 V/div`，时基 `5 ms/div`）：
  - 如果看到了稳定的 **`60 Hz`（周期 16.67ms）、幅值 `1.8V` 的方波/窄脉冲** → **大功告成一半！**说明电源、复位和初始化命令已经全部被屏幕正确接收，屏幕内部控制器已经正常刷新，剩下只需排查图像数据通道（MIPI Lane 映射或显存格式）！
  - 如果 `TE` 一直是一条 `0V` 直线 → 说明上电时序、复位或初始化指令没被屏幕识别，先回头查 `1.8V` 电平、MIPI `LP` 波形和 `dsi-panel-*.dtsi` 里的命令序列。

## 7. 总结：给你的务实推荐路线

1. **想先把二手手机屏当模拟/高速电路项目玩透**：
   - 先查你手上那几块二手手机屏的**具体手机型号** → 去 GitHub 搜它的 `dsi-panel-*.dtsi` 确认驱动 IC 和几条 Lane；
   - 如果是 **2-Lane MIPI 屏**，直接选 **ESP32-P4** 开发板 + 自画一张 **4 层供电与 BTB 转接板**（`ME6211` 1.8V/2.8V + `TPS65132` ±5.5V + `SY7200A` 恒流背光）；
   - 如果是 **手表/小尺寸 QSPI 屏**，直接上 **ESP32-S3（带 8MB PSRAM）**，无需复杂 100Ω MIPI 差分阻抗！
2. **如果你把手上二手手机屏的具体型号发给我**，我可以帮你查它的接口类型、几条 MIPI Lane、需要几路供电，甚至帮你评估能不能直接驱动！
