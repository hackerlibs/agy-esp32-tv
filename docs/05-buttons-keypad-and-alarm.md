# 05. 扩展实战：加按键 / 键盘与闹钟功能的电路设计

把小电视加上**物理按键 / 旋转编码器 / 键盘**以及**闹钟提醒（蜂鸣器 + 时钟保持）**，它就从「被动显示屏」升级成了真正能交互的桌面终端：旋钮调亮度/翻页、按键静音或确认权限、定点响铃提醒休息或会议、甚至 AGY 遇到 `WAIT INPUT`（`ask_question`）时响一声柔和提示音。

这篇从 **ESP32-C3 剩余引脚预算** 出发，给出每套电路的完整模拟原理图、元件参数选型、踩坑点，以及如何用你的示波器/万用表实测验证。

---

## 1. 先盘点 ESP32-C3 剩余可用引脚（GPIO 预算）

在画电路之前，必须先算清楚芯片还剩多少「干净」的引脚可用。本项目目前占用情况：

| 引脚 | 当前用途 | 能否复用？ |
|---|---|---|
| `GPIO1` | 屏幕背光 PWM（LEDC Timer 0 / Ch 0） | 已占 |
| `GPIO2` | 屏幕 DC（兼 Strapping 脚） | 已占 |
| `GPIO3` | 屏幕 SCLK | 已占 |
| `GPIO5` | 屏幕 MOSI | 已占 |
| `GPIO6` | 屏幕 RST | 已占 |
| `GPIO12 ~ 17` | 片内/片外 QSPI Flash | **严禁碰** |
| `GPIO18, 19` | 内置 USB-Serial/JTAG（`D-` / `D+`） | **已占** |
| `GPIO20, 21` | 硬件 UART0（`RX` / `TX`） | 强烈建议留给 USB-TTL 救砖调试 |
| **`GPIO0`** | **空闲（支持 ADC1_CH0）** | **推荐：单脚多键 ADC 键盘 / 按键 / 蜂鸣器** |
| **`GPIO4`** | **空闲（支持 ADC1_CH4）** | **推荐：I2C SDA / 旋钮 A 相 / 按键** |
| **`GPIO7`** | **空闲（纯数字脚）** | **推荐：旋钮 B 相 / 按键 / 蜂鸣器** |
| **`GPIO10`** | **空闲（纯数字脚）** | **推荐：无源蜂鸣器 PWM / 旋钮按压 SW** |
| **`GPIO8`** | 空闲（Strapping 脚，开机须为高电平） | **可用：I2C SCL（本身带 4.7kΩ 上拉，开机天然高电平！）** |
| **`GPIO9`** | 开发板 BOOT 键（开机拉低进下载模式） | **开机后可免费复用作普通按键！（只要上电瞬间不按住就行）** |

结论：不占用串口调试口的前提下，我们手上稳稳有 **4 个完全自由的脚（`GPIO0, 4, 7, 10`）+ 2 个开机高电平脚（`GPIO8, 9`）= 6 个可用 GPIO**。

## 2. 按键与键盘电路设计（4 种方案按需选择）

### 方案 A：独立按键（1~4 个键，最简单可靠）

适合需求：**「上一页 / 下一页 / 确认 / 闹钟静音」** 等少量功能键。

#### 原理图（低电平有效 + RC 硬件消抖）
```text
                        +3.3V
                          │
                         [R1] 10kΩ (上拉电阻；也可省略改用芯片内部 ~45kΩ 上拉)
                          │
                          ├──────[R2 1kΩ]──────┬────► ESP32 GPIO (如 GPIO0 / GPIO7)
                          │                    │
                       ┌──┴──┐                ═╪═ C1 = 0.1uF (104 瓷片电容)
                       │ SW  │ 轻触开关         │
                       └──┬──┘                 │
                          │                    │
                         GND                  GND
```

#### 模拟电路细节（为什么多画了 `R2` 和 `C1`？）
1. **机械抖动（Bounce）**：普通轻触开关金属弹片闭合/断开瞬间，会产生持续 **`5 ~ 20 ms`** 的剧烈弹跳毛刺，直接进数字口会被误判成连按好几次。
2. **`R1` + `C1` 低通滤波**：
   - 按键松开时，充电时间常数 $\tau_1 = (R_1 + R_2) C_1 \approx 11\text{k}\Omega \times 0.1\mu\text{F} = 1.1\text{ms}$；
   - 按键按下时，`C1` 通过 **`R2 (1kΩ)`** 放电（$\tau_2 = 0.1\text{ms}$），**`R2` 的作用是限制电容瞬间短路放电电流**（没有 `R2` 时，电容直接通过开关触点短路，火花电流会加速触点氧化，同时在 GND 上产生尖峰噪声）。
3. **配合软件消抖**：硬件 `0.1uF` 滤掉微秒级高频毛刺，软件再做 `20ms` 状态稳定判断，即可丝滑区分**单击 / 双击 / 长按（如长按 2 秒进闹钟设置）**。
4. **复用 `GPIO9` 的零成本彩蛋**：几乎每块 ESP32-C3 开发板都自带一颗接在 `GPIO9` 到 `GND` 的 `BOOT` 键，芯片进入 `app_main()` 后 `GPIO9` 就是普通输入脚，直接拿它当「切换界面 / 关闹钟」键，一根线都不用焊！

### 方案 B：EC11 旋转编码器 + 中心按压（强烈推荐给桌面小电视！）

在 240×240 小屏幕上调闹钟时间（时/分）、调背光亮度（0~100%）、切换页面，**一颗 EC11 旋钮（约 ¥2）比 4 个独立按键好用十倍**，且只需 **3 个 GPIO**。

#### 原理图
```text
             +3.3V     +3.3V     +3.3V
               │         │         │
             10kΩ      10kΩ      10kΩ
               │         │         │
               ├──1kΩ──┬─┼──► GPIO4 (ENC_A)
               │      ═╪═ 0.01uF (103)
    EC11       │       │
   ┌─────┐     │      GND
   │  A  ├─────┘
   │  C  ├───── GND    (公共端)
   │  B  ├─────┬──1kΩ──┬────► GPIO7 (ENC_B)
   │     │     │      ═╪═ 0.01uF (103)
   │     │   (上拉同上) │
   │     │            GND
   │ SW1 ├─────┬──1kΩ──┬────► GPIO9 或 GPIO10 (ENC_SW 中心按压)
   │ SW2 ├─────┤      ═╪═ 0.1uF (104)
   └─────┘    GND     GND
```
*(注意：旋钮 `A/B` 通道快速旋转时脉冲较窄，滤波电容选 **`0.01uF (103)`** 比 `0.1uF` 更合适，既消抖又不吞脉冲。)*

#### 正交相位原理（示波器双通道超好看！）
```text
  顺时针旋转 (CW):   A 超前 B 90°         逆时针旋转 (CCW):  B 超前 A 90°
  A: ───┐   ┌───┐   ┌───                 A: ─────┐   ┌───┐   ┌───
        └───┘   └───┘                            └───┘   └───┘
  B: ─────┐   ┌───┐   ┌───               B: ───┐   ┌───┐   ┌───
          └───┘   └───┘                        └───┘   └───┘
          ▲                                      ▲
      A下降沿时 B=1 → CW                     A下降沿时 B=0 → CCW
```
软件只需在 `A` 变化时查 `B` 的电平（或用 4 状态格雷码状态机），就能精确无误地识别顺时针/逆时针加减。

### 方案 C：单引脚 ADC 电阻梯形键盘（AD Key，最省 GPIO 的模拟玩法！）

如果你想要 **5~6 个独立按键**（如 `上 / 下 / 左 / 右 / 确认 / 返回`），但只舍得花 **1 个引脚（`GPIO0` / `ADC1_CH0`）**，用模拟分压电路（电阻梯形网络）极其优雅：

#### 原理图（1 脚接 5 键）
```text
                      +3.3V
                        │
                      [R0] 10kΩ (1% 精密电阻)
                        │
                        ├───────────────────────┬──► GPIO0 (ADC1_CH0)
                        │                       │
      ┌────────┬────────┼────────┬────────┐    ═╪═ 0.1uF (抗干扰滤波)
      │        │        │        │        │     │
    [SW1]    [SW2]    [SW3]    [SW4]    [SW5]  GND
      │        │        │        │        │
     0Ω     [R1]     [R2]     [R3]     [R4]
    (直连)  2.2kΩ    5.6kΩ    12kΩ     33kΩ
      │        │        │        │        │
     GND      GND      GND      GND      GND
```

#### 各按键对应的分压值（$V_{ADC} = 3.3\text{V} \times \frac{R_k}{R_0 + R_k}$）

| 按下的键 | 对地电阻 $R_k$ | 理论电压 $V_{ADC}$ | 软件判定窗口（留足余量） |
|---|---|---|---|
| **SW1** | `0 Ω` | **`0.00 V`** | `< 0.30 V` |
| **SW2** | `2.2 kΩ` | **`0.60 V`** | `0.35 V ~ 0.85 V` |
| **SW3** | `5.6 kΩ` | **`1.18 V`** | `0.95 V ~ 1.45 V` |
| **SW4** | `12 kΩ` | **`1.80 V`** | `1.55 V ~ 2.10 V` |
| **SW5** | `33 kΩ` | **`2.53 V`** | `2.25 V ~ 2.85 V` |
| 无按键 | `∞` | **`3.30 V`** | `> 3.00 V` |

#### ESP32-C3 ADC 必知避坑点
1. **务必接在 `ADC1`（`GPIO0 ~ GPIO4`），不要用 `ADC2`（`GPIO5`）**：开启 Wi-Fi 时 ADC2 会被射频硬件占用导致读数失败，而 `GPIO0`（`ADC1_CH0`）和 `GPIO4`（`ADC1_CH4`）全程不受 Wi-Fi 影响。
2. **量程衰减选 `ADC_ATTEN_DB_12`**：ESP32-C3 ADC 原始满量程仅 ~0.75V，配 `12dB` 衰减后可测 `0 ~ 2.5V+`；注意在 `2.6V ~ 3.3V` 顶端非线性较明显，所以上面的 SW5 故意设计在 `2.53V` 以内，并且每档之间留了 ≥0.5V 的宽裕死区（用 1% 金属膜电阻即可稳如泰山）。
3. **不支持同时按两个键**（多键并发会并联电阻改变分压），适合菜单/闹钟设置，不适合游戏手柄。

### 方案 D：16 键 / 完整数字小键盘（I2C IO 扩展芯片）

如果你真的想接一块 **`4×4` 矩阵键盘**（输闹钟时间、发快捷命令给 AGY），直接扫描需要 `4 + 4 = 8` 个 GPIO，ESP32-C3 剩下的引脚根本不够。

**最佳工程解法：加一颗 ¥2 的 I2C 扩展芯片（`PCF8574` 8 位 / `TCA9555` 16 位）**！
- 它只占用 **2 根 I2C 线（`SDA=GPIO4, SCL=GPIO8`）**，还能和下面的 **DS3231 实时时钟芯片** 挂在**同一条 I2C 总线上**（零额外引脚开销！）：
  - `PCF8574`（地址 `0x20`）：8 个扩展 IO → 直接接 `4×4` 矩阵键盘（4 行 + 4 列）！
  - `DS3231`（地址 `0x68`）：时钟芯片挂在同一对 `SDA/SCL` 上！
- **多键防鬼影提示**：如果 `4×4` 矩阵键盘需要支持组合键（同时按多个键），在每个按键下方串联一颗 **`1N4148`** 小信号二极管即可彻底杜绝「鬼影按键」。

## 3. 闹钟功能电路设计（发声 + 精准走时 + 断电不丢）

一个好用的硬件闹钟由三部分组成：**① 发声电路**、**② 精准时钟源**、**③ 闹钟数据存储**。

### 3.1 发声电路：有源蜂鸣器 vs 无源蜂鸣器 vs I2S 小喇叭

| 方案 | 驱动方式 | 声音效果 | 占用引脚 | 推荐度 |
|---|---|---|---|---|
| 有源蜂鸣器 (3.3V) | GPIO 高低电平开关 | 只有单调「滴——」（约 2.3kHz） | 1 | 一般 |
| **无源蜂鸣器（电磁式，推荐）** | **LEDC PWM 输出不同频率** | **可播音乐旋律、柔和双音提示音（闹钟 + AGY `WAIT INPUT` 提示！）** | **1 (`GPIO10`)** | **强烈推荐（¥1~2）** |
| MAX98357A + 8Ω 1W 小喇叭 | I2S 数字音频 | 真语音 / WAV / MP3 铃声 | 3 (`BCLK/LRC/DIN`) | 进阶玩法 |

#### 无源电磁蜂鸣器标准驱动电路（模拟电路关键：**续流二极管！**）
```text
                            +3.3V (或 5V，注意选对应额定电压的蜂鸣器)
                              │
                    ┌─────────┴─────────┐
                    │                   │
                 ┌──┴──┐               ─┴─  D1: 1N4148 或 1N5819 (肖特基)
                 │ BUZ │ 电磁无源蜂鸣器  ▲   【反并联续流二极管，阴极接 +3.3V！】
                 │ 16Ω │                │
                 └──┬──┘                │
                    └─────────┬─────────┘
                              │
                              C
   GPIO10 ──[R1 1kΩ]───┬───── B  Q1: NPN 三极管 (S8050 / 2N2222)
   (LEDC PWM)          │      E      或 N-MOSFET (AO3400 / 2N7002，此时 R1 可改 100Ω)
                    [R2 10kΩ] │
                       │      │
                      GND    GND
```

> **为什么反并联二极管 `D1` 绝对不能省？（模拟电路核心知识点）**
> 电磁式蜂鸣器内部就是一个带铁芯的**电感线圈**。当 `Q1` 导通时线圈储能（电流约 `50~100mA`）；PWM 下降沿 `Q1` 瞬间关断时，根据 $V = -L \frac{di}{dt}$，线圈会产生高达 **20V ~ 50V 的反向感应电动势尖峰**！
> - **不加 `D1`**：这个高压尖峰直接打在 `Q1` 集电极上（轻则引起 3.3V 电源毛刺让 ESP32 复位/花屏，重则击穿三极管）；
> - **加上 `D1`**（阴极接 `+3.3V`，阳极接 `Q1` 集电极）：关断瞬间电感电流通过 `D1` 形成续流回路，尖峰电压被牢牢钳位在 `3.3V + 0.7V = 4.0V`！
> - **补充**：如果你买的是**压电陶瓷片（Piezo）无源蜂鸣器**（本质是电容而非电感），则不需要 `D1`，而是在蜂鸣器两端并联一颗 **`1kΩ` 泄放电阻**，让电荷在半周期内快速释放、声音更响亮。

**PWM 驱动频率参考**（ESP32-C3 用 `LEDC_TIMER_1` + `LEDC_CHANNEL_1`，和背光的 `TIMER_0` 互不冲突）：
- 设占空比 **50%**（`duty = 128` @ 8-bit）声音最大，设 `duty = 0` 静音；
- 改变定时器频率即可奏出音阶：中音 `Do = 523 Hz`、`Re = 587 Hz`、`Mi = 659 Hz`、`Sol = 784 Hz`、`La = 880 Hz`，谐振点通常在 **`2000 ~ 2700 Hz`** 最响亮（适合闹钟叫醒）。

### 3.2 闹钟走时与断电保持（3 种方案对比）

| 方案 | 额外硬件 | 精度 | 断电后时间是否保留 | 适用场景 |
|---|---|---|---|---|
| **方案 1：主机串口校时** | 无 | 跟电脑同步 | 否（重启等主机发帧） | 一直连着电脑当 AGY 桌面副屏 |
| **方案 2：ESP32 Wi-Fi + SNTP** | 无（芯片自带 Wi-Fi） | 误差 < 50ms | 上电连 Wi-Fi 后 2 秒自动校准 | 独立插 5V 充电头当桌面闹钟 |
| **方案 3：DS3231 高精度 RTC 模块** | DS3231 + CR2032（~¥6） | 温补晶振，**年误差 < 2 分钟** | **是（断电靠纽扣电池走时 3~5 年）** | 离线真闹钟、随时拔插不丢时间 |

#### DS3231 I2C 接线与重要安全避坑！
```text
                   +3.3V          +3.3V
                     │              │
                   4.7kΩ          4.7kΩ  (注：市售 DS3231 模块板载已自带上拉电阻，无需重复焊)
                     │              │
  ESP32 GPIO4 ───────┴──────────────┼────► DS3231 SDA  (同时可并联 PCF8574 SDA)
  ESP32 GPIO8 ──────────────────────┴────► DS3231 SCL  (同时可并联 PCF8574 SCL)
  ESP32 3V3   ───────────────────────────► DS3231 VCC
  ESP32 GND   ───────────────────────────► DS3231 GND
```

> **安全警告（淘宝蓝色 ZS-042 DS3231 模块必看！）**：
> 很多廉价蓝色 DS3231 模块板载了一个简陋的充电电路（一颗标着 `201` 的 `200Ω` 电阻 + 一颗玻璃二极管，连接 `VCC` 到电池正极），原本是给可充电的 LIR2032 用的。**如果你装的是普通不可充电的 CR2032 锂电池，请用烙铁挑掉这颗 200Ω 电阻或二极管！** 否则 3.3V 持续给 CR2032 充电会导致电池鼓包甚至漏液。

### 3.3 闹钟设置掉电保存（NVS 分区注意）

注意本仓库当前 [partitions.csv](../partitions.csv) 为了**绝对不碰原厂 `0x9000` 处的 NVS（Wi-Fi 密码等）**，没有挂载 NVS 分区。如果你需要把闹钟时间（比如 `08:30`、开关状态、偏好亮度）保存在板子 Flash 里断电不丢：
- 可以在 [partitions.csv](../partitions.csv) 的空闲区域末尾（原厂 `0x310000` 相册之前！）单独辟一块 **`16KB` 的私有 NVS 分区**，完全不碰原厂 NVS 和原厂相册：
  ```csv
  # Name,   Type, SubType, Offset,   Size, Flags
  factory,  app,  factory, 0x10000,  0x2E0000,
  agy_nvs,  data, nvs,     0x2F0000, 0x4000,
  ```
- 代码中用 `nvs_flash_init_partition("agy_nvs")` 读写闹钟时间和默认亮度，既掉电记忆，又 100% 保留随时还原原厂固件的能力！

## 4. 推荐整机「完全体」引脚规划（零冲突方案）

把 **ST7789 屏幕 + EC11 旋钮 + 无源蜂鸣器 + DS3231 时钟（+ 可选 PCF8574 键盘）** 全部塞进这一颗 ESP32-C3，正好严丝合缝、零冲突、且还完整保留了 `GPIO20/21` 串口调试口：

| ESP32-C3 引脚 | 分配功能 | 备注 |
|---|---|---|
| `GPIO1` | 屏幕背光 PWM（LEDC Timer 0） | 现有 |
| `GPIO2` | 屏幕 DC | 现有（Strapping 脚，勿接下拉） |
| `GPIO3` | 屏幕 SCLK | 现有 |
| `GPIO5` | 屏幕 MOSI | 现有 |
| `GPIO6` | 屏幕 RST | 现有 |
| **`GPIO4`** | **I2C SDA**（接 DS3231 + 可选 PCF8574） | 若不加 I2C，可改接 EC11 `A` 相 |
| **`GPIO8`** | **I2C SCL**（接 DS3231 + 可选 PCF8574） | I2C 自带上拉，满足 Strapping 开机高电平要求 |
| **`GPIO0`** | **EC11 `A` 相**（或 ADC 5 键键盘） | 支持 ADC1_CH0 |
| **`GPIO7`** | **EC11 `B` 相**（或独立按键） | 纯数字脚 |
| **`GPIO9`** | **EC11 中心按压 `SW`**（复用 BOOT 键） | 开机后作确认/贪睡/静音键 |
| **`GPIO10`** | **无源蜂鸣器 PWM（LEDC Timer 1）** | 经 S8050 + 1N4148 驱动 |
| `GPIO18 / 19` | USB-Serial/JTAG | 现有（连电脑 AGY bridge & 刷机） |
| `GPIO20 / 21` | UART0 调试口 | 留空给 USB-TTL 救砖 |

## 5. 软件融入现有固件的清晰架构

等硬件搭好后，往现有项目里加功能只需新增 2~3 个小模块，完全不破坏原来的分层：

1. **`main/input.c`（独立输入任务，优先级 5）**：
   - 每 `5 ms` 扫描一次按键 / EC11 / ADC 键盘，完成消抖和短按/长按识别，把事件（`EV_CW`、`EV_CCW`、`EV_CLICK`、`EV_LONG`）发给 FreeRTOS 队列或直接更新 `zmodel`：
     - 普通状态下旋转 EC11 → 直接调用 `panel_set_brightness()` 丝滑调背光！
     - 长按 → 切入「闹钟设置页」（旋转调小时/分钟，短按确认）；
     - 响铃状态下短按 → 贪睡 5 分钟，长按 → 关闭闹钟。
2. **`main/buzzer.c`（蜂鸣器任务，使用 `LEDC_TIMER_1` + `LEDC_CHANNEL_1`）**：
   - 提供非阻塞接口 `buzzer_play(MELODY_ALARM)`、`buzzer_play(MELODY_WAIT_INPUT)`、`buzzer_play(MELODY_DONE)`、`buzzer_stop()`；
   - 收到 AGY `WAIT INPUT`（`ask_question`）时轻响两声「叮咚」，收到 `ERROR` 时低音短鸣，闹钟到点循环播放旋律。
3. **`main/ui.c` + `main/zmodel.h`**：
   - 在 `ds_t` 增加 `DS_ALARM_RING`（红/琥珀交替闪烁大字时间 + `PRESS TO STOP`）和 `DS_ALARM_SET`（大字调时界面），同样先用 `tools/uitest/run.sh` 在电脑上渲染验收后再刷真机！
4. **`main/zlink.c` 扩展串口命令（可选）**：
   - 支持电脑直接设闹钟：`ZTV1 C alarm="08:30"`、`ZTV1 C alarm=off`、`ZTV1 C beep`，方便用命令行或 AGY `/schedule` 联动小电视响铃！

## 6. 用你的仪器实测验收（示波器 + 万用表 + 逻辑分析仪）

搭好扩展电路后，别急着写复杂软件，先用你的仪器做 4 个超有成就感的实测：

1. **示波器抓按键抖动 & 验证 RC 消抖**：
   - 探头接开关两端（未加 `C1` 前），`Single` 单次触发下降沿，时基 `2 ms/div`，按一下开关——你会亲眼看到触点弹跳出 3~8 个杂乱毛刺；
   - 再焊上 `R2 (1kΩ)` + `C1 (0.1uF)` 测 GPIO 端，毛刺瞬间变成一条干净利落的指数下降曲线！
2. **示波器双通道看 EC11 正交波形**：
   - `CH1` 接 `A`，`CH2` 接 `B`，时基 `2 ms/div`，分别顺时针、逆时针拧一格，能直观看到两路方波 90° 的超前/滞后翻转。
3. **示波器看电磁蜂鸣器的电感反冲尖峰（模拟电路经典实验！）**：
   - `CH1`（`10X` 探头，`5 V/div`）接在 `Q1` 集电极上，给 `GPIO10` 输出 `2 kHz` 方波；
   - 对比接上 `1N4148` 续流二极管前后的波形：接上后尖峰被干净削平在 ~4V，电源轨纹波同步大幅降低。
4. **万用表查 ADC 键盘各档电压 & 逻辑分析仪解 DS3231 I2C**：
   - 逐个按 `SW1 ~ SW5`，万用表直流电压档实测 `GPIO0` 电压并与第 2 节表格核对；
   - 逻辑分析仪挂 `SDA / SCL` + PulseView 添加 **`I2C`** 解码器，能直接看到读写地址 **`0x68`** 及秒/分/时 BCD 字节。
