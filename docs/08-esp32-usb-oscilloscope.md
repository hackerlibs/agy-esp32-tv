## 1. 先定清楚系统架构：采样率、带宽与「手机屏幕」的两种组合玩法

做示波器前，必须先算清楚 **ADC 采样率 vs 可测带宽**（一般单次捕获看清波形至少需要每周期 8~10 个采样点）：

| 方案档位 | 采样硬件 | 最高采样率 | 实用干净模拟带宽 | 能测什么？ |
|---|---|---|---|---|
| **入门版（零外置 ADC，直插 ESP32-C3 / S3）** | ESP32 内置 12-bit ADC（`adc_continuous` DMA） | **~83.3 kSPS** | **DC ~ 10 kHz** | 音频、5kHz 背光 PWM、RC 充放电、运放电路、传感器、电源低频纹波 |
| **进阶高速版（外挂并口 ADC）** | **ESP32-S3 (`LCD_CAM` 8-bit 并口 DMA) / ESP32-P4 + `AD9280`（8-bit 32MSPS，约 ¥8）** | **20 ~ 32 MSPS** | **DC ~ 3 ~ 5 MHz** | SPI / I2C / UART、开关电源 500kHz 开关波形、超声波、多数单片机数字与模拟信号 |

### 「ESP32 + 手机屏幕 + USB 示波器」的两种落地路线（本板同时支持！）

1. **路线 A：手机作为 USB 示波器屏幕（最省事、分辨率最高！）**
   - 直接在 [esp32_usb_scope](../hardware/esp32_usb_scope/) 上插 **ESP32-C3 SuperMini**（或外接 **ESP32-S3**），用 **USB OTG 线**插到安卓手机（或电脑 USB 口），ESP32 通过 USB-CDC 连续推送二进制采样帧，手机/电脑跑波形上位机（WebSerial / Android USB Serial / Python），直接享受手机 1080p 大屏触控缩放；同时板上自带 `J_LCD` 也可插 1.54" 屏脱机查看。
2. **路线 B：拆机二手手机屏 + ESP32-P4（独立便携大屏示波器）**
   - 如果要把二手手机屏（如 2-Lane MIPI 屏，见 [07-smartphone-screen-to-esp32.md](./07-smartphone-screen-to-esp32.md)）直接做到示波器里，**不要插 U1 (ESP32-C3)**，而是直接从板子左下角的 **`J_EXT` 4 针模拟前端引出排针（`GND, AVDD, AFE_OUT, CAL_1KHZ`）** 接到 **ESP32-P4（或 ESP32-S3 + AD9280）**，本板摇身一变成为独立的 **AFE 模拟前端模块**！

## 2. 示波器核心：6 级模拟前端（AFE）电路精讲

任何一台真示波器的灵魂都不是单片机，而是 **模拟前端（Analog Front-End, AFE）**。普通单片机 ADC 只能采 `0 ~ 3.3V` 正电压且输入阻抗低，必须经过下面 6 级模拟调理，才能像台式示波器一样安全地接上标准 **10X / 1X 示波器探头** 测正负电压：

```text
  标准 BNC 探头                                                               进 ESP32 ADC (GPIO0)
  (±20V / ±4V)                                                                或外接 AD9280
       │
       ▼
  ┌──────────┐   ┌──────────────────┐   ┌──────────┐   ┌────────────────┐   ┌──────────┐
  │ 1.AC/DC  │──►│ 2. ~1MΩ 频率补偿 │──►│ 3.二极管 │──►│ 4.双运放 U2    │──►│ 5.抗混叠 │──► AFE_OUT
  │ 耦合切换 │   │ 单电源电平搬移   │   │ 过压钳位 │   │ 缓冲 + x1/x4.7 │   │ RC 滤波  │
  └──────────┘   └──────────────────┘   └──────────┘   └────────────────┘   └──────────┘
```

### 第 1 级：BNC 输入 + AC/DC 耦合切换（`J_BNC`、`C_AC`、`SW_CPL`）
- **`J_BNC`**：标准母座，直接拧上你手头已有的示波器 1X/10X 探头。
- **`C_AC`（`0.1uF / 250V` CBB 薄膜电容）**：交流耦合时阻断直流偏置，只让交流信号通过；配合后级 `~1MΩ` 输入阻抗，高通截止频率为：
  $$f_c = \frac{1}{2\pi R C} \approx \frac{1}{2\pi \times 960\text{k}\Omega \times 0.1\mu\text{F}} \approx 1.66\text{ Hz}$$
  （20Hz 以上音频和电源纹波几乎零衰减！）
- **`SW_CPL`（SPDT 拨动开关）**：拨向 `DC` 直通，拨向 `AC` 串入 `C_AC`。

### 第 2 级：单电源 `~1 MΩ` 频率补偿分压与负压电平搬移（模拟电路精华！）
传统示波器为了测负电压（如 `-10V`），往往要搭 `-5V` 负电源（既费器件又有电荷泵开关噪声）。本电路采用**单 3.3V 供电电阻偏置网络**，零负电源即可原生测量 **`-20V ~ +20V`**：

```text
                                         +3.3V (AVDD)
                                              │
                         C_COMP (5-30pF)   [R_UP 100kΩ 1%]
                       ┌──────═╪═──────┐      │
  CPL_OUT ─────────────┴──[R_IN 910kΩ]─┴──────┼──────┬──► AFE_N1 (进运放 U2A+)
                                              │      │
                                         [R_DN 100kΩ] ═╪═ C_ATT (180pF C0G)
                                              │      │
                                             GND    GND
```

我们来用戴维南定理（Thevenin）验算一下这组精妙的参数：
1. `R_UP (100kΩ → 3.3V)` 与 `R_DN (100kΩ → GND)` 等效为 **`R_th = 50 kΩ` 接到 `1.65V`**；
2. BNC 探头看到的直流输入阻抗：$R_{in} = 910\text{k}\Omega + 50\text{k}\Omega = \mathbf{960\text{k}\Omega \approx 1\text{ M}\Omega}$（完美匹配标准 10X 示波器探头！）；
3. 节点 `AFE_N1` 的精确电压公式：
   $$V_{N1} = 1.65\text{V} \times \frac{910}{960} + V_{in} \times \frac{50}{960} = \mathbf{1.564\text{V} + 0.0521 \cdot V_{in}}$$
   - 当输入 $V_{in} = 0\text{V}$ 时：$V_{N1} = \mathbf{1.56\text{V}}$（正处单电源运放与 ADC 线性区正中！）；
   - 当输入 $V_{in} = +20\text{V}$ 时：$V_{N1} = \mathbf{2.61\text{V}}$（安全落在 `0~3.3V` 内！）；
   - 当输入 $V_{in} = -20\text{V}$ 时：$V_{N1} = \mathbf{0.52\text{V}}$（依然是**正电压**，单电源运放毫无削波！）。
4. **为什么一定要加 `C_COMP`（5~30pF 可调电容）和 `C_ATT`（180pF）？**
   - 没有电容时，`910kΩ` 电阻和运放/PCB 约 `10~15pF` 的输入寄生电容会构成一个 **$f_c \approx 15\text{ kHz}$ 的低通滤波器**，高频方波会严重圆角！
   - 当把 `C_COMP` 拧到满足 **$R_{in} \cdot C_{COMP} = R_{th} \cdot (C_{ATT} + C_{parasitic})$**（即 $910\text{k}\Omega \times 10\text{pF} \approx 50\text{k}\Omega \times 182\text{pF}$）时，分压比从直流到数 MHz 完全平坦！

### 第 3 级：输入过压钳位保护（`D_P1`、`D_P2`）
- 两颗 `1N4148`（或更低结电容的 `BAV99`）分别把 `AFE_N1` 钳位在 **`AVDD + 0.6V`** 和 **`GND - 0.6V`** 之间。
- 即使误触 30V~50V 电压，电流也被前级 `910kΩ` 限流在 `< 50 uA`，完全不会损坏运放或 ESP32！

### 第 4 级：双轨到轨运放 `U2`（DIP-8 插座：缓冲 + `×1 / ×4.7` 档位切换）
本板特意采用 **DIP-8 底座**，方便你按带宽需求随时换芯片：
- 配合 ESP32 内置 ADC（~10kHz 带宽）：插 **¥1 的 `MCP6002`**（1MHz 轨到轨）或 **`TLC2272`**（2.2MHz）；
- 以后升级外置 `AD9280` 高速 ADC（~3~5MHz 带宽）：直接拔下来换成 **`OPA2350`**（38MHz，配 SOIC-8 转 DIP-8 小板）或 **`AD8066`**（145MHz）！

两路运放分工如下：
- **`U2A`（电压跟随器）**：极高输入阻抗隔离前级 `910kΩ` 网络，输出低阻信号 `V_BUF`；
- **`U2B`（`×1` / `×4.72` 程控/开关增益级）**：
  - `SW_GAIN` 拨到 **`×1`（断开）**：反相端只经 `R_FB (39kΩ)` 接输出 → 单位增益 **1.00×**，量程 **`±20V`**（配 10X 探头可测更高，但 DIY 非隔离安全上限请严守 `±30V`！）；
  - `SW_GAIN` 拨到 **`×5`（闭合）**：反相端接到由 `R_REF1 (22kΩ → 3.3V)` 和 `R_REF2 (20kΩ → GND)` 组成的 **`1.571V` 虚拟中点**（戴维南阻值 `10.48kΩ`，与 `1.564V` 零点误差仅 `7mV`！），增益 $G = 1 + \frac{39}{10.48} = \mathbf{4.72\times}$，量程变为高灵敏度的 **`±4V`**（连几十毫伏小信号都清晰可见！）。

### 第 5 级：抗混叠滤波（`R_AAF` + `C_AAF`）与干净模拟电源（`AVDD`）
- **抗混叠滤波器**：`R_AAF (1kΩ)` + `C_AAF` 组成一阶 RC 低通：
  - 若使用 ESP32 内置 `83kSPS` ADC，建议把 `C_AAF` 焊成 **`10nF (103)`**（$f_c \approx 16\text{ kHz}$，有效压制高于奈奎斯特频率 41kHz 的混叠噪声）；
  - 若从 `J_EXT` 接高速外部 ADC（如 20MSPS），焊 **`1nF (102)`**（$f_c \approx 160\text{ kHz}$）甚至 `100pF`（$f_c \approx 1.6\text{ MHz}$）。
- **模拟电源退耦**：数字 `3V3` 经过 `R_AV (10Ω)` + `C_AV1 (10uF)` + `C_AV2 (100nF)` 低通滤波后变成 **`AVDD`** 单独供给运放和偏置网络，滤除 ESP32 与屏幕的高频数字毛刺。

### 第 6 级：`1 kHz` 探头补偿校准方波（`CAL_1KHZ`）
- 与台式示波器面板右下角的方波挂钩一模一样！ESP32 的 `GPIO10` 用 LEDC 输出精准 `1.000 kHz / 50%` 方波，经 `R_CAL (1kΩ)` 限流送到 `J_EXT` 的第 4 脚 `CAL`。

## 3. 安全红线（USB 示波器必读！）

> **⚠️ 严禁测量 220V 市电或非隔离开关电源初级侧！**
> 这台 USB 示波器的 **BNC 探头接地鳄鱼夹直接与电脑/手机的 USB 地线（GND）相连**！如果你把鳄鱼夹夹在带电的零火线或非隔离电源热地上，电流会经 USB 线直接短路到电脑主板和大地，轻则烧毁 ESP32 和电脑 USB 口，重则触电！
> - **安全测量范围**：各类电池供电电路、5V/12V/24V 隔离直流电源电路、单片机/运放/音频电路（峰值电压严格限制在 **`±30V`** 以内）。
> - 若确实需要完全隔离测量：可在电脑与 ESP32 之间串联一个 **ADuM3160 USB 隔离器**（约 ¥30），或脱机用充电宝供电查看本机屏幕。

## 4. 软件固件与 USB 传输架构

1. **高速采样（ESP-IDF `adc_continuous` 连续 DMA 模式）**：
   - 在 `GPIO0`（`ADC_CHANNEL_0`, `ADC_ATTEN_DB_12`）上开启 83.3kSPS 连续 DMA 采入环形缓冲（无需 CPU 干预，每次中断收满 1024 个点）；
   - 电压还原公式（根据 `SW_GAIN` 档位）：
     - `×1` 档：$V_{in} = \frac{V_{adc} - V_{zero}}{0.0521}$
     - `×4.72` 档：$V_{in} = \frac{V_{adc} - V_{zero}}{0.246}$
     *(开机时先短接探头到 GND 自动测一次 `V_zero` 做软件归零校准，精度极高！)*
2. **软件边沿触发（Trigger）**：
   - 在 DMA 缓冲区中搜索满足 `sample[i-1] < trig_level && sample[i] >= trig_level`（上升沿）的索引，以此对齐画面左边缘，波形立刻稳稳冻住不乱跑！
3. **双路输出**：
   - **本机屏幕**：直接复用本项目的 `gfx.c` 单帧缓冲（240×240 暗网格背景 + 亮黄色波形折线 + 顶部 `Vpp / Freq / Timebase` 读数），用 EC11 旋钮实时调时基和触发电平；
   - **USB 上位机 / 手机 App**：以简单二进制帧（帧头 `0xAA 0x55` + 采样率 + 512 点 uint16 + CRC）通过 USB-CDC 持续发给电脑 Python `matplotlib`/`pyqtgraph` 或安卓手机 USB Serial 波形软件。

## 5. 用你手头的台式示波器校准这台 DIY 示波器（4 步验收）

你手头已经有一台真正的台式示波器，这是调试自制示波器最好的「标尺」：

1. **空载中点验证（万用表）**：
   - 焊好板子只供 3.3V，不接信号输入，测 `AVDD ≈ 3.30V`、`AFE_N1 ≈ 1.56V`、`V_BUF ≈ 1.56V`；
   - `SW_GAIN` 切 `×1` 测 `AFE_OUT ≈ 1.56V`；切 `×5` 测 `AFE_OUT ≈ 1.54V`（都在线性区正中！）。
2. **用你的台式示波器看 `AFE_OUT` 校准 `C_COMP`（最爽的一步！）**：
   - 把 DIY 示波器的 BNC 探头夹到 `J_EXT.4 (CAL_1KHZ)`（1kHz 方波）；
   - 把**你的台式示波器探头**点在 `J_EXT.3 (AFE_OUT)` 上；
   - 用塑料起子轻轻拧 **`C_COMP`（5~30pF 可调电容）**，看着台式示波器上的 1kHz 方波从「过冲尖角」或「圆角」调到**横平竖直的完美直角方波**——频率补偿校准完成！
3. **验证线性度与负压测量**：
   - 找一节 1.5V 干电池（或 5V/12V 直流电源）**正接和反接**到 BNC 输入，确认 `AFE_OUT` 相对 `1.56V` 精确对称地向上/向下偏移，且换算出的电压误差 < 3%。
4. **验证抗混叠与底噪**：
   - 把 BNC 探头直接夹到自身地线（输入 0V），用台式示波器 AC 耦合测 `AFE_OUT` 的噪声峰峰值：正常应 **< 10~20 mVpp**（干净一条直线）。

## 6. 未来升级到 20~32 MSPS（接入外部高速 ADC `AD9280`）

当你把上面这套 AFE 玩透后，想测几 MHz 的高速波形，**完全不用重画模拟前端**：
1. 把 `U2` 底座里的 `MCP6002` 换成高速运放 **`OPA2350`**，把 `C_AAF` 换成 `47pF`；
2. 买一块淘宝 ¥15 的 **`AD9280` 高速 ADC 模块（8-bit / 32MSPS）**，把本板的 `J_EXT.3 (AFE_OUT)` 接到 `AD9280` 的模拟输入端（`AD9280` 输入范围正好是 `0 ~ 2V` 或 `0.5 ~ 2.5V`，和本板输出完美匹配！）；
3. `AD9280` 的 8 位并行数据线 `D0~D7` + `CLK` 接到 **ESP32-S3 的 `LCD_CAM` 并口 DMA** 或 **ESP32-P4**，即可瞬间升级成 **20~32 MSPS 真高速便携示波器**，屏幕同步升级为 [07 篇](./07-smartphone-screen-to-esp32.md) 的二手手机 MIPI 大屏！
